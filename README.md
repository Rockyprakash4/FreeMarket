# \# DevMarket – Freelance Marketplace Platform

# 

# \*\*DevMarket\*\* is a web-based freelance marketplace platform that connects clients with skilled freelancers. It allows clients to post projects, receive proposals, hire freelancers, manage orders, and handle payments through a centralized platform.

# 

# \## 🚀 Features

# 

# \- \*\*User Authentication:\*\* User registration, login, and profile management.

# \- \*\*Freelancer Profiles:\*\* Browse freelancers and explore their profiles.

# \- \*\*Project Marketplace:\*\* Clients can post, browse, and manage freelance projects.

# \- \*\*Proposal Management:\*\* Freelancers can submit proposals for available projects.

# \- \*\*Messaging System:\*\* Communication between clients and freelancers.

# \- \*\*Notifications:\*\* Stay updated with important platform activities.

# \- \*\*Order Management:\*\* Manage freelance orders and project progress.

# \- \*\*Payment Management:\*\* Track payment information and transactions.

# \- \*\*Reviews \& Ratings:\*\* Share feedback and build trust within the marketplace.

# \- \*\*Dashboard:\*\* Access relevant project and account information.

# \## ⚙️ Installation \& Setup

# 

# \### 1. Clone the repository

# 

# ```bash

# git clone https://github.com/Rockyprakash4/FreeMarket.git

# cd FreeMarket

# ```

# 

# \### 2. Create a virtual environment

# 

# ```bash

# py -m venv venv

# ```

# 

# \### 3. Activate the virtual environment

# 

# \*\*Windows PowerShell:\*\*

# 

# ```powershell

# .\\venv\\Scripts\\Activate.ps1

# ```

# 

# \### 4. Install Python dependencies

# 

# ```bash

# py -m pip install -r requirements.txt

# ```

# 

# \### 5. Install frontend dependencies

# 

# ```bash

# npm install

# ```

# 

# \### 6. Configure environment variables

# 

# Create a `.env` file using `.env.example` as a reference.

# 

# Configure your database connection, secret key, and other required settings.

# 

# \### 7. Run database migrations

# 

# ```bash

# py manage.py migrate

# ```

# 

# \### 8. Start the development server

# 

# ```bash

# py manage.py runserver

# ```

# 

# Open your browser:

# 

# ```text

# http://127.0.0.1:8000/

# ```
